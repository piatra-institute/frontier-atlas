# Batch sweep: refute matroid conjectures on small matroids

**Mode:** one ChatGPT Pro session, code sandbox, batch throughput.
**Goal:** an explicit small matroid violating a stated conjecture, or hardened survivors. Refutation is the clean win.

**Family + panel.** Matroids on small ground sets; data: rank function, bases, circuits, the Tutte polynomial, characteristic polynomial, Whitney numbers (independent-set counts I_k), representability over small fields, and the Ingleton inequality value. Track the h-vector of the independence complex.

**Enumerate.** All matroids to n=8 elements (count-check A055545: 1,2,4,8,17,38,98,306,1724 for n=0..8; n=9 is 383172, reachable if time). Use the SageMath matroid catalogue / Matsumoto-Moriyama-Imai enumeration as the generation source and cross-check counts.

**Conjecture generation.** Anchor on named statements: White's conjecture (the toric ideal of a matroid is generated by symmetric-exchange quadrics; open); Rota's basis conjecture (n disjoint bases arrange into n common-transversal bases; open); the Ingleton inequality (satisfied by representable matroids, violated by some non-representable ones — a witness search); and log-concavity of I_k (a theorem, Adiprasito-Huh-Katz / Branden-Huh — use as a validation self-check). Auto-fit Whitney-number and Tutte-evaluation inequalities.

**Adversarial families.** Non-representable matroids (Vamos, non-Fano, non-Desargues), paving matroids, sparse paving matroids (the bulk of all matroids), uniform and partition matroids, and Dilworth truncations.

**Checker (exact).** Verify matroid axioms (exchange property) exactly; recompute Whitney numbers, Ingleton terms, and representability by exhaustive small-field search. Emit violators as explicit bases lists.

**Verification discipline.** Generator is not verifier: recompute rank/bases/circuits with a second implementation and confirm axioms; re-derive log-concavity as an internal audit (it must never fail). Cite each conjecture, noting which are proven. Report candidates generated / broken / survived, with matroid witnesses.
