# A record-distance graph state (self-dual additive GF(4) code)

**Find:** a graph on n vertices whose associated self-dual additive code over GF(4), equivalently an [[n,0,d]] stabilizer/graph state, has minimum distance d exceeding the best known for that length.

## What counts as a win
An explicit adjacency matrix (symmetric, zero diagonal, over GF(2)) whose graph state has distance d' beating the tabulated record. One-sided: a new record entry.

## Checker
The graph state's stabilizer is generated by X_i prod_{j~i} Z_j. Its distance equals the minimum weight of a nonzero element of the corresponding self-dual additive GF(4) code, computed exactly by minimum-weight search over the 4^n / symplectic structure for small n (n up to about 30). Self-duality is automatic for a graph state; verify the generators commute. Runtime: seconds to minutes.

## Search plan
Local complementation orbits move within equivalence classes; search across classes by edge add/swap hill-climbing on distance, seeded by circulant and strongly regular graphs. Confirm each distance with an independent additive-code minimum-weight routine.

## Prior art (verify)
Self-dual additive GF(4) codes (= graph states = [[n,0,d]] codes) are classified/tabulated for small n by Danielsen-Parker (2006) and in Grassl's codetables.de; best distances at larger n are records that get improved. Re-verify the current best for the chosen n.
