# What comes next

## Current frontier

The current work proves that the group generated by the normalized matching permutations of
any hypothetical solution must be one of:

```text
PSL(3,4).2_3
PSL(3,4).2_1
PSL(3,4).2_2
PSL(3,4).2^2
Alt(56)
Sym(56)
```

It excludes every semiregular/regular group construction, the primitive `Alt(8)` and `Sym(8)`
actions, and the base `PSL(3,4)` action. This is a strong local reduction, not a resolution of
the Moore-graph problem.

## Priority 1: finish the four finite extension-group cases

There are 12 canonical first-level exact-cover instances in `extension_instances/`.
The immediate computational task is to decide each instance exactly.

The existing DLX implementation can search them, but it needs two upgrades before its output
meets a publication-grade nonexistence standard:

1. On SAT, print the selected row IDs and reconstruct the 56 permutations as a directly
   checkable sharply transitive set.
2. On UNSAT, emit a complete search-tree certificate, or translate the instance to a
   proof-producing SAT encoding and save a DRAT/LRAT certificate with an independent checker.

Use at least two independent implementations. Validate instance hashes before solving.
A short smoke test on `g3_A0.txt` did not finish within 20 seconds with the unmodified DLX
solver, so naïve depth-first exact cover is not sufficient evidence that these branches will be
cheap. Add conjugacy-aware branching, class-count propagation, and memoization/canonical
state hashing before launching a full sweep.

### Deliverable

A table for all 12 branches containing:

```text
group, branch, instance SHA-256, SAT/UNSAT, nodes/conflicts,
certificate hash, checker command, checker result
```

## Priority 2: extract constraints from any surviving sharply transitive sets

Even if an extension contains one sharply transitive 56-set, that is only one normalized
column of the rooted matching system. Enumerate orbit representatives of such sets under the
normalizer and compute pairwise compatibility under the exact block equation

```text
sum_{h != i,j} P_ih P_hj = J - P_ij.
```

Build a compatibility graph or higher-order constraint system whose vertices are canonical
sharply transitive sets and whose cliques/solutions correspond to multiple compatible fibre
columns. This is the first point at which the search begins to enforce global closure rather
than merely local sharp transitivity.

### Deliverable

A canonical database of local solutions, stabilizers, orbit sizes, pairwise compatibility
counts, and hashes. If no compatible pair or triple exists, this can eliminate an entire group
case with a much smaller certificate than a 3250-vertex SAT instance.

## Priority 3: attack the universal `Alt(56)` / `Sym(56)` cases

Eliminating the four small extensions would still leave `Alt(56)` and `Sym(56)`. A strategy
that merely enumerates group elements cannot handle these groups. The next mathematical goal
must therefore be a universal invariant coupling at least two normalized columns.

The strongest current formulation is the symmetric `3136 x 3136` zero-one matrix `B` with
56-by-56 permutation blocks satisfying

```text
B^2 - B = 56I + J - P - Q,
BP = PB = J,
BQ = QB = J.
```

Equivalently, there are 56 coupled Latin squares with an exact near-orthogonality law. Promising
concrete targets are:

1. Derive triple- and quadruple-intersection identities from the matrix equation and project
   them onto the `8`, `0`, and `-7` eigenspaces.
2. Reduce those identities modulo 2, 5, and 7, looking for rank or parity contradictions that
   do not assume any automorphism.
3. Study the coherent configuration generated by the two fibre equivalence relations `P,Q`
   and `B`; determine whether closure forces additional relations or impossible integral
   intersection numbers.
4. Search for a theorem limiting families of order-56 Latin squares with the required
   multiplicity pattern. This is more universal than classifying permutation groups.
5. Encode progressively larger canonical partial systems, but certify that the symmetry
   breaking uses only fibre/label relabellings available to every arbitrary solution.

## Priority 4: global proof-producing search

Only after the universal reductions are strengthened should a full solver be built. The
recommended architecture is:

```text
canonical generator -> SAT/CP-SAT clauses -> proof-producing solver
                    -> LRAT/VeriPB certificate -> independent checker
```

The encoding must include all block equations and retain automorphism-free cases. Regression
must pass on the degree-2, degree-3, and degree-7 Moore graphs.

## Decision rule

The next decisive milestone is not merely “all 12 extension branches are UNSAT.” It is one of:

- a new universal identity excluding `Alt(56)` and `Sym(56)` as well;
- a globally compatible partial system large enough to expose new forced structure;
- a certified global UNSAT reduction whose exhaustiveness does not assume symmetry;
- an explicit complete graph satisfying the defining matrix equation.
