# Degree-57 Moore graph: exact reductions, primitive-group classification, and one finite exclusion

## 1. Result status

The target is a simple graph with

```text
(v,k,lambda,mu) = (3250,57,0,1),
A 1 = 57 1,
A^2 = 56 I - A + J.
```

This package does **not** contain a complete construction or a proof of nonexistence. The
problem therefore remains unresolved. It does contain the following rigorously checked
progress:

1. an exact equivalence with a `(57,56,1)` distance-regular antipodal cover of `K_57`;
2. an exact system of 56-point matching permutations and a compressed 3136-by-3136
   zero-one matrix formulation;
3. a proof excluding every semiregular group-of-derangements construction, including all
   cyclic, abelian, and nonabelian regular covers;
4. a universal representation restriction forcing every nontrivial constituent of the
   generated 56-point permutation action to have dimension divisible by 5;
5. a proof that the generated matching group must be primitive;
6. an exhaustive use of the complete primitive-group list in degree 56, eliminating the
   `Alt(8)` and `Sym(8)` actions;
7. an independently checked exact-cover computation eliminating the remaining base action
   of `PSL(3,4)`.

Consequently, if the Moore graph exists, the group generated by its normalized matching
permutations must be permutation-isomorphic to one of exactly six actions:

```text
PSL(3,4).2_3,  PSL(3,4).2_1,  PSL(3,4).2_2,
PSL(3,4).2^2,  Alt(56),       Sym(56).
```

This is a necessary-condition reduction, not a resolution. Even a sharply transitive subset
in one of the surviving groups would be only the first local requirement; the full system
couples 57 fibres simultaneously.

## 2. Full graph spectrum

On the all-one vector, `A` has eigenvalue 57. On its orthogonal complement, `J=0`, so

```text
A^2 + A - 56 I = 0.
```

The remaining eigenvalues are 7 and -8. If their multiplicities are `f,g`, then

```text
f+g=3249,
57 + 7f - 8g = tr(A)=0.
```

Hence

```text
Spec(A) = {57^1, 7^1729, (-8)^1520}.
```

The spectrum is feasible and does not itself decide existence.

## 3. Exact rooted decomposition

Fix a vertex `u`. Its 57 neighbors are pairwise nonadjacent. Call them
`b_0,...,b_56`. Every remaining vertex is adjacent to exactly one `b_i`; otherwise a
triangle or 4-cycle occurs. The 3192 distance-two vertices therefore split into fibres

```text
X_i = N(b_i) minus {u},       |X_i|=56.
```

Every vertex of `X_i` has exactly one neighbor in every `X_j`, `j != i`. Thus every pair of
distinct fibres is joined by a perfect matching.

Order the vertices as `(u,b_0,...,b_56,X_0,...,X_56)`. Let `R` be the 57-by-3192 fibre
incidence matrix and `C` the adjacency matrix induced on the distance-two vertices. Then

```text
A = [ 0   1^T   0  ]
    [ 1    0    R  ]
    [ 0   R^T   C  ],

R R^T = 56 I_57,
R^T R = P := I_57 tensor J_56.
```

Comparing blocks in `A^2 = 56I-A+J` gives

```text
C R^T = J - R^T,
R C   = J - R,
C^2   = 56 I - C + J - P.                         (1)
```

Conversely, a symmetric zero-one matrix `C` with zero diagonal, zero diagonal fibre blocks,
permutation off-diagonal blocks, and equation (1) reconstructs the full Moore graph by adding
`u` and the 57 branch vertices. This is an exact equivalence.

### 3.1 Distance-regular antipodal cover

The graph with adjacency matrix `C` has degree 56. Its fibres are antipodal classes and its
intersection array is

```text
{56,55,1; 1,1,56}.
```

Thus the Moore problem is equivalent to the existence of a `(57,56,1)` distance-regular
antipodal cover of `K_57`, often abbreviated DRACKN.

### 3.2 Spectrum of the rooted cover

The fibre-constant subspace has quotient matrix `J_57-I_57`, giving eigenvalues 56 once and
-1 with multiplicity 56. On `ker R`, both `J` and `P` vanish, so (1) becomes

```text
C^2 + C - 56 I = 0.
```

Trace zero then gives

```text
Spec(C) = {56^1, 7^1672, (-1)^56, (-8)^1463}.
```

## 4. Exact matching-permutation formulation

Label every fibre by the same 56-element set. Let `P_ij` be the permutation matrix of the
matching from `X_i` to `X_j`, with

```text
P_ii=0,
P_ji=P_ij^T.
```

Relabel each fibre independently so that, for one distinguished fibre `X_0`,

```text
P_0i = P_i0 = I_56       for i != 0.               (2)
```

The normalization is essential; an arbitrary labelling does not make these blocks identities.
Equation (1) then gives, for every `i != 0`,

```text
I + sum_{j != 0,i} P_ji = J_56.                    (3)
```

The 56 permutations in (3) form a sharply transitive set: for every ordered pair of labels
`(x,y)`, exactly one permutation maps `x` to `y`.

For distinct `i,j`, the off-diagonal block equation is

```text
sum_{h != i,j} P_ih P_hj = J_56 - P_ij.            (4)
```

Equations (2)-(4), transpose symmetry, and the permutation constraints are an exact finite
formulation. Any solution reconstructs the graph.

## 5. Excluding all semiregular group constructions

### Theorem

The matching system cannot be contained in a semiregular permutation group on the 56 labels.
Consequently no regular group cover, cyclic or nonabelian, can produce the degree-57 Moore
graph.

### Proof

Assume every matching permutation belongs to a semiregular group `G <= S_56`. Every orbit of
a semiregular action has size `|G|`, so `|G|` divides 56. Equation (3) supplies 55 pairwise
distinct nonidentity elements of `G`; equality of two matching permutations would create a
4-cycle. Hence `|G| >= 56`, and therefore

```text
|G|=56.
```

The action is regular.

Every group of order 56 has a nontrivial one-dimensional complex character. Let `n_7` be the
number of Sylow 7-subgroups. Then `n_7` is 1 or 8.

- If `n_7=1`, quotienting by the normal Sylow 7-subgroup gives a group of order 8, which has
  a quotient of order 2.
- If `n_7=8`, the eight Sylow 7-subgroups contribute 48 distinct nonidentity elements. The
  remaining seven nonidentity elements, together with the identity, form the unique Sylow
  2-subgroup. It is normal and the quotient has order 7.

Thus `G` has a nontrivial linear character `chi`.

In the regular action, each matching block is a regular permutation matrix `P(g_ij)`. Apply
`chi` to every group-algebra block in (1). Since

```text
sum_{g in G} chi(g)=0,
```

both `J` and `P` disappear. The result is a 57-by-57 Hermitian matrix `S_chi` satisfying

```text
S_chi^2 + S_chi = 56 I_57,
tr(S_chi)=0.                                        (5)
```

Its eigenvalues are 7 and -8. If their multiplicities are `a,b`, then

```text
a+b=57,
7a-8b=0.
```

This forces `a=152/5`, impossible. The contradiction proves the theorem.

This argument strictly extends the published cyclic exclusion. It is independent of the 2026
no-involutions theorem, although that theorem also excludes a regular deck group of order 56.
No claim of literature priority is made here.

## 6. Universal representation restriction and primitivity

Let `Gamma <= S_56` be the group generated by all matching permutations of an arbitrary
solution. Equation (3) contains a sharply transitive subset, so `Gamma` is transitive.
Decompose the natural permutation module over the complex numbers as

```text
C^56 = 1 direct_sum U.
```

Let `rho` be a nontrivial irreducible constituent of `U`, of dimension `d`. Restrict every
56-by-56 matching block in (1) to a copy of `rho`. The `J` and `P` terms vanish there, giving
a `57d`-dimensional Hermitian matrix with eigenvalues 7 and -8 and trace zero. Their
multiplicities are

```text
m_7  = 152d/5,
m_-8 = 133d/5.
```

Therefore

```text
5 divides d.                                        (6)
```

### 6.1 The generated group must be primitive

Suppose `Gamma` preserved a nontrivial block system with `m` blocks. The subspace of vectors
constant on each block has a zero-sum submodule of dimension `m-1`. Since complex
representations are semisimple and every nontrivial constituent has dimension divisible by 5,
this submodule must have dimension divisible by 5.

The proper nontrivial numbers of blocks dividing 56 are

```text
m in {2,4,7,8,14,28},
```

so

```text
m-1 in {1,3,6,7,13,27}.
```

None is divisible by 5. Hence `Gamma` is primitive.

## 7. Complete primitive-group reduction in degree 56

The bundled PrimGrp 4.0.2 excerpt lists exactly nine primitive permutation groups of degree
56, up to permutation isomorphism. The scripts enumerate the first seven from the official
generators and verify their orders, subdegrees, derangement counts, and relevant orbital graph
identities.

```text
idx  group                 order       subdegrees       nontrivial module     result
---  --------------------  ----------  ---------------  --------------------  ----------------
 1   PSL(3,4)                 20160     10,45            20,35                 exact-cover fail
 2   PSL(3,4).2_3             40320     10,45            20,35                 survives
 3   PSL(3,4).2_1             40320     10,45            20,35                 survives
 4   PSL(3,4).2_2             40320     10,45            20,35                 survives
 5   PSL(3,4).2^2             80640     10,45            20,35                 survives
 6   Alt(8)                   20160     10,15,30         7,20,28               excluded by (6)
 7   Sym(8)                   40320     10,15,30         7,20,28               excluded by (6)
 8   Alt(56)               56!/2       55               55                    survives
 9   Sym(56)               56!         55               55                    survives
```

For groups 1-5, the valency-10 orbital graph satisfies exactly

```text
A_G^2 = 8I - 2A_G + 2J,
```

so it is the Gewirtz strongly regular graph with nontrivial eigenspace dimensions 20 and 35.
The actions have rank 3, hence those two eigenspaces are the two nontrivial irreducible
constituents. Both dimensions pass (6).

For groups 6-7, the valency-15 orbital graph has exact spectrum

```text
15^1, 7^7, 1^20, (-3)^28.
```

Its 7-dimensional invariant eigenspace lies in `U`, contradicting (6). Thus both actions are
impossible. The rank-2 actions of `Alt(56)` and `Sym(56)` have one nontrivial constituent of
dimension 55 and are not eliminated by (6).

## 8. Exact-cover exclusion of the base PSL(3,4) action

A sharply transitive subset `S` of a permutation group is equivalent to

```text
sum_{s in S} P(s) = J_56.                           (7)
```

Left multiplication lets us assume that the identity belongs to `S`. Every other element is
then a derangement.

In the degree-56 action of `PSL(3,4)`, exact conjugacy enumeration gives four derangement
classes:

```text
kind       number of classes   class size   chi_20   chi_35
---------- ------------------  -----------  -------  -------
order 4             2              1260        0       -1
order 7             2              2880       -1        0
```

Here `chi_20` and `chi_35` are obtained from the exact spectral projectors of the valency-10
orbital graph. Restricting (7) to the 20- and 35-dimensional constituents and taking traces
forces every normalized sharply transitive set to contain exactly

```text
35 order-4 derangements and 20 order-7 derangements. (8)
```

In particular, it contains an order-4 element. There are two order-4 conjugacy classes. For
each class, conjugate the putative set so that it contains a fixed representative `p` of that
class. The identity covers the 56 diagonal cells of the 56-by-56 array and `p` covers 56
off-diagonal cells. The remaining problem is an exact cover:

```text
remaining cells:       3136 - 56 - 56 = 3024
remaining permutations to select:       54
candidate derangements compatible with p: 3400
cells covered by each candidate:         56
```

The two conjugacy-class branches are finite and exhaustive. Two independent implementations
produce identical search counts:

```text
branch   Python bitset solver       C++ dancing-links solver
------   ------------------------   -------------------------
0        UNSAT, 2416 nodes, depth 8 UNSAT, 2416 nodes, depth 8
1        UNSAT, 2526 nodes, depth11 UNSAT, 2526 nodes, depth11
```

The C++ solver uses no character-class quota during the search; it checks the raw exact-cover
instances. The branch files and their hashes are included. Therefore:

### Theorem

`PSL(3,4)` in its primitive degree-56 action contains no sharply transitive subset. Hence the
group generated by the matchings of a hypothetical Moore graph cannot equal this
`PSL(3,4)` action.

This exclusion is only for group 1 in the table. A sharply transitive set in one of the four
proper extensions can use elements outside `PSL(3,4)` and is not ruled out by this computation.

## 9. Compressed 3136-by-3136 formulation

Set `N=I+C`, normalize as in (2), and delete the rows and columns belonging to `X_0`. Call the
remaining matrix `B`. It is a symmetric zero-one matrix of order `56^2=3136`, partitioned
into 56-by-56 blocks. Every block, including every diagonal block, is a permutation matrix.

Define

```text
P = I_56 tensor J_56,
Q = J_56 tensor I_56,
J = J_3136.
```

Exact block elimination gives

```text
B^2 - B = 56 I + J - P - Q,                         (9)
BP = PB = J,                                        (10)
BQ = QB = J.                                        (11)
```

The forced spectrum is

```text
Spec(B) = {56^1, 8^1617, 0^110, (-7)^1408}.
```

Equivalently, `M=B-I` is a distance-regular graph with intersection array

```text
{55,54,2; 1,1,54}
```

and spectrum

```text
{55^1, 7^1617, (-1)^110, (-8)^1408}.
```

### 9.1 Latin-square form

For each block row `i`, define

```text
L_i(x,j) = p_ij(x),
```

where `B_ij` is the permutation matrix of `p_ij`. Equation (11) makes every `L_i` a Latin
square of order 56. For `i != h`, equation (9) says that the superposition of `L_h` and `L_i`
has the following exact multiplicities for output pairs `(y,z)`:

```text
0 times if z=y,
2 times if z=p_ih(y),
1 time otherwise.
```

Thus a solution would give 56 mutually coupled, derangement-indexed, nearly orthogonal Latin
squares. This is an equivalent reformulation, not an obstruction by itself.

## 10. Regression checks on known Moore graphs

`verify_known_moore.py` checks the full adjacency equation, rooted decomposition, permutation
blocks, compressed identities, and redundant spectra using exact integer arithmetic on:

```text
degree 2: the 5-cycle,
degree 3: the Petersen graph,
degree 7: the Hoffman-Singleton graph.
```

All exact checks pass. This is important because the degree-7 example is nonregular in the
relevant matching sense; a reduction that silently assumes a regular deck group would
incorrectly exclude known Moore behavior.

## 11. Exact remaining gap

A complete resolution still requires either a construction satisfying (2)-(4), or a proof
that none exists. After the reductions above, the generated matching group must be one of

```text
PSL(3,4).2_3,  PSL(3,4).2_1,  PSL(3,4).2_2,
PSL(3,4).2^2,  Alt(56),       Sym(56).
```

The next finite layer is to decide, with proof certificates, whether each of the four
`PSL(3,4)` extensions contains even one sharply transitive 56-set. Excluding all four would
still leave the natural `Alt(56)` and `Sym(56)` actions. Moreover, a local sharply transitive
set is necessary but not sufficient: equations (4) require 57 such systems to close globally.

A complete computational nonexistence proof would therefore need:

1. exhaustive canonical generation under only justified relabellings;
2. exact enforcement of all block equations, not a restricted symmetric ansatz;
3. independently checkable unsatisfiability certificates;
4. validation on degrees 2, 3, and 7;
5. a complete manifest of source, versions, counts, and hashes.
